理解を助ける説明資料

文章を読み進めながら、必要なところで比較や図を使う。補足は開いて読み、用語欄は必要に応じて閉じられます。

  1. 説明の流れをつくる
  2. 違いを並べて捉える
  3. 関係を図で補う
  4. 補足を必要なときに読む
  5. 表記と出典を揃える

見出しで道筋を示し、文章で意味をつなぎます。図や表は、理解の助けになる箇所に置きます。

説明の流れをつくる

まず、何を理解するための資料なのかを示します。前提を揃えたら本題へ進み、身近な例を通じて確かめます。読み手が次の段落へ自然に進めるよう、一つの段落では一つの話を扱います。

図を置く場所は内容に合わせて決めます。冒頭の文章だけで要点が伝わる場合は、そのまま説明を続けます。専門用語は本文で短く説明し、繰り返し参照するものを用語欄にもまとめます。

違いを並べて捉える

共通の観点で見比べたいときは、比較する対象を横に並べると違いを捉えやすくなります。狭い画面では縦に並びます。

文章

理由や条件を順に説明します。背景と結果をつなぎ、細かな違いにも言葉を添えられます。

図表

位置関係や対応を同時に見せます。全体と部分の関係や、同じ観点での違いを捉える助けになります。

伝えたいこと使える表現
理由や背景つながりのある文章
対象間の違い比較表や並置したカード
全体と部分包含関係を表す図
単純な手順番号付きの説明

関係を図で補う

たとえば「資料には本文と補足が含まれる」という関係は、外枠と内側の領域で表せます。文章の一部を単に箱へ移すのではなく、図の位置や大きさに意味を持たせます。

補足を必要なときに読む

説明の筋道は、補足を開かなくても追えるようにします。追加の背景や細かな条件は、見出しを押すと読める形にまとめます。

詳しく：折りたたみに入れる内容

理解を深める追加例、細かな前提、例外的な条件などを入れます。本論の意味を変える重要な条件は、本文にも明記します。

用語欄を閉じても、本文での用語説明は残ります。印刷では補足と用語欄を含めて読み通せます。

詳しく：この見本の配色

背景は生成り #FAF9F6、面は白、見出しと罫線は黒です。リンクに青 #2990DA、強いアクセントに赤 #D63A2F を使います。

表記と出典を揃える

分類には 文章 比較 図解 のような小さなラベルを使えます。引用は出典を添え、原文と訳文を同じ大きさで並べます。

This is a sample quotation.

これは引用の見本です。

出典：この見本用に作成した例文

コードは言語を明示します。次の例はHTMLとして表示しているだけで、コードの実行は行いません。

<details class="mb-details">
  <summary>補足を読む</summary>
  <p>必要なときに読める説明。</p>
</details>

コード差分は理由を説明してから示します。たとえば補足を最初は閉じておく場合、open 属性を外します。

<details class="mb-details" open>
<details class="mb-details">

デザインの出典は mathbullet/skills の html スキルです。この見本はCSSとJavaScriptを埋め込んだ1つのHTMLで、ネット接続なしでも表示と開閉ができます。

用語

本文
理解してほしい内容を、筋道に沿って説明する中心の文章。
補足
本論に加えて、詳しく知りたいときに読む説明。
並置
対象を並べて、共通点や違いを見比べられるようにすること。
包含関係
あるものが、別のものの一部として含まれている関係。
単一HTML
見た目と操作に必要な情報を埋め込み、1ファイルで開けるHTML。
