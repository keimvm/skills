# 会話を要件メモにまとめる

ここまでの会話を読み返し、ユーザーがあとから内容や考えをつかみ直せるよう、要件を簡潔にまとめてください。

- 対象の指定がなければ、この会話全体を対象にします。話題ごとに整理し、後から変更・撤回された内容は最新の意向に合わせてください。
- 「目的」「決まった要件・方針」「未決事項」を基本に、必要な見出しだけを使います。なぜそう考えたかは、会話に出ている理由を該当する項目に短く添えてください。
- ユーザーの要望や合意した内容と、AIが提案しただけの内容を区別してください。採用が確認できない案や解消していない矛盾は、必要なものだけ未決事項に残します。
- 重複や会話の経過は省き、要件の意味を変える条件・制約は残してください。会話にない要件や理由を推測で補わないでください。
- 不明点を埋めるための追加質問はせず、未決のまま簡潔に記します。新しい提案や実装作業には進みません。
- 出力前に会話と照らし、重要な要件の抜けや、未決事項を決定済みとする記述がないか確認してください。

通常はチャットにMarkdownの本文をそのまま出力し、前置きやまとめ方の解説は付けません。ファイル保存を求められた場合は、その指定に従ってください。
