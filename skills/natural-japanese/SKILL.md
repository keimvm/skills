# 自然な日本語に整える

AIの回答を、ユーザー自身があとから読み返しても無理なく理解できる文章に整えてください。伝える内容は変えず、言葉の選び方、説明の量、話の流れを読み手に合わせます。短くすること自体は目的ではありません。

## 進め方

1. ユーザーが指定した文章を対象にします。指定がなければ直前のAIの回答を使い、対象が分からない場合だけ短く確認してください。
2. 会話から、ユーザーが知りたいことと、すでに共有されている前提を捉えてください。文体の指定がなければ、落ち着いた「です・ます」調を基本にします。
3. 書き直す前に、原文の答えの核と、それを理解するために必要な理由・条件・例外を捉えてください。同じ役割の説明はまとめ、読み手が知りたい順に並べます。全体の構成を決めてから、一文ずつ表現を整えてください。
4. 書き直した後に原文と見比べ、次の「変えないもの」が保たれているか確認してください。意味の保持に加え、同じ主張を繰り返していないか、話題の切り替わりを追えるかも確認してください。内容のまとまりに応じて短い見出しを付けてください。

## 変えないもの

- 意味、事実、条件、例外、確かさの度合い。判断に必要な理由も残します。
- 数値、固有名詞、引用、出典リンク。
- コードブロック、コマンド、ファイルパス、識別子。そのまま残します。
- 原文にない事情や書き手の意図は、推測で補いません。二通りに読める箇所は、どちらかに決めずに曖昧さを保ちます。
- 保つのは、伝えている内容とその確かさです。段落の数や順序、同じ内容を説明する回数は変えてかまいません。ただし、似た説明でも条件や適用範囲が異なる場合は、その違いを残してください。

## 文章の整え方

- 要点を早めに示し、一つの段落や章立てでは一つの話を扱います。前の文を受けて次の文が自然につながる順序にしてください。
- 身近で具体的な言葉を使います。専門用語が必要なら、その場で短く意味を添え、会話で使っている呼び方に合わせてください。
- 理解に必要な前提や因果関係が省かれている箇所だけ、短く補ってください。すでに伝わる内容の言い直しや、周辺の話題への広がりは省きます。例は、抽象的な説明の助けになる場合だけ添え、事実と区別できる書き方にします。
- 主語や接続詞は、なくても関係が分かる箇所で省き、曖昧になる箇所には残します。短い文を基本にしつつ、意味のまとまりに応じて長さを調整し、短文や体言止めを機械的に並べないでください。
- 箇条書きは、内容を追いやすくなる場合に使います。決まったルールに当てはめず、文章に合う章立てや段落構成にしてください。演出だけの比喩や対比、感情の付け足しは避けます。

## よくある型と扱い

AIの文章に多い型です。語を一律に禁止せず、何を伝えたいのかが直接分かる形に整えてください。必要な留保や意味は保ちます。

| 型 | 扱い |
| --- | --- |
| 「〜することが重要です」「〜と言えるでしょう」が続く | 何がどう重要なのか、なぜそう言えるのかを直接述べる |
| 「以下に説明します」「まとめると」「ぜひお試しください」などの前置きと締め | 省き、本文から始めて本文で終える |
| 「〜することができます」「〜を行う」「〜に関しては」 | 「〜できます」「〜する」「〜は」と直接言う |
| 「非常に」「まさに」「〜かもしれません」「基本的には」の連発 | 意味を変える箇所だけに残す |
| 「シームレス」「インサイト」「ベストプラクティス」などのカタカナ語 | 日本語で言えるものは言い換え、会話で使っている呼び方があればそれに合わせる |
| 全体が箇条書き・太字・番号付き | つながりのある話は文章に戻し、並列の項目だけ箇条書きにする |

## 出力

整えた本文をそのまま返してください。書き直しの宣言や変更点の解説は付けません。追加の提案は求められた場合だけ、原文の意味が取れず確認が要る箇所は本文の後に一言だけ添えます。
